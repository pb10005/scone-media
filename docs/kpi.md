## 北極星指標（North Star Metric）

> **月間アクティブ回遊セッション数**
>
> 定義：1セッション内で2ページ以上（異なるコンテンツページ）を閲覧したセッションの月間合計数

### なぜこの指標か

- このサイトの目的は「発見・回遊体験」であり、UU数だけでは質を捉えられない
- PV数は同一ユーザーの大量リロードで膨れる
- 「2ページ以上回遊」はコンテンツへの関心が確認できた最低ラインである
- 計測：GA4で「エンゲージしたセッション」またはカスタムイベントで代替可能

---

## KPI階層

```
北極星指標：月間アクティブ回遊セッション数
    ↑
Input KPI（先行指標）
    ├── コンテンツ公開本数（月次）
    ├── SNSシェア数（月次）
    └── 検索流入セッション数（月次）
    ↑
Output KPI（成果指標）
    ├── 月間UU
    ├── PV/セッション
    ├── 平均エンゲージメント時間
    └── リピーター率
```

## GA4 イベント設計

### カスタムイベント一覧

| イベント名 | 発火タイミング | パラメータ |
|---|---|---|
| `anthology_view` | アンソロジー企画詳細ページ表示 | `anthology_slug`, `tag_list` |
| `work_view` | 収録作詳細ページ表示 | `work_slug`, `anthology_slug`, `format` |
| `article_view` | 記事詳細ページ表示 | `article_slug`, `article_type`, `tag_list` |
| `spot_view` | スポット詳細ページ表示 | `spot_slug` |
| `tag_click` | タグリンクをクリック | `tag_name`, `tag_category`, `source_page_type` |
| `related_anthology_click` | 関連企画リンクをクリック | `target_anthology_slug`, `source_page_type` |
| `related_work_click` | 収録作一覧 or 関連収録作リンクをクリック | `target_work_slug`, `source_page_type` |
| `related_article_click` | 関連記事リンクをクリック | `target_article_slug`, `source_page_type` |
| `share_click` | シェアボタンをクリック | `platform`, `content_type`, `content_slug` |
| `next_work_click` | 「次の収録作」ナビをクリック | `target_work_slug`, `anthology_slug` |
| `contribute_click` | 寄稿についてページへの導線クリック | `source_page` |

### イベント実装方針

- GA4のカスタムイベントは `gtag()` または Google Tag Manager（GTM）で実装
- パラメータはすべて文字列型。`tag_list` はカンマ区切り文字列（例：`"短編,郷愁,夜"`）
- フレームワーク（Next.js等）のルーターに合わせてページビュートラッキングを設定する

## 計測できない指標と代替策

| 本来測りたいこと | 直接計測の難しさ | 代替指標 |
|---|---|---|
| 作品への感動・満足度 | 主観的・定量化困難 | 平均エンゲージメント時間、SNSシェア数 |
| 再読行動 | 同一セッション内の判定困難 | リピーター率・特定作品への複数回訪問 |
| 寄稿意向 | フォーム未設置はゼロ計測 | `/contribute`ページPV・クリック数 |
| 口コミ・口頭推薦 | 計測不能 | 直接参照流入（Direct）の増減で間接観察 |
