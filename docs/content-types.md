# コンテンツタイプ定義

> フェーズ0設計書の付属ドキュメント  
> 作成日: 2026-04-28

---

## 概要

スコーン・ポータルで扱うコンテンツタイプを定義する。  
CMSのスキーマ設計・フロントエンドのテンプレート設計の基準とする。

---

## 1. アンソロジー企画（anthology）

### 説明

テーマを定めた作品集企画。複数の収録作を束ねる「親コンテンツ」。  
サイトの看板コンテンツであり、回遊の起点となる。

### フィールド定義

| フィールド名 | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `title` | String | ○ | 企画タイトル | 「夜の縁側」 |
| `slug` | String | ○ | URLスラッグ（英数字ハイフン） | `yoru-no-engawa` |
| `description` | Text | ○ | 企画概要（200〜400字推奨） | テーマの説明文 |
| `theme` | String | ○ | テーマキーワード（1〜3語） | 「郷愁、夜、日常」 |
| `cover_image` | Image | ○ | 表紙画像（OGP兼用） | 1200×630px推奨 |
| `tags` | Tag[] | ○ | 関連タグ（3〜5個） | `["短編", "現代文学", "郷愁"]` |
| `works` | Work[] | ○ | 収録作リスト（順序付き） | 紐付けID参照 |
| `published_at` | DateTime | ○ | 公開日時 | `2026-05-01T10:00:00Z` |
| `editor_note` | Text | - | 編集後記・編集者コメント | 任意 |
| `status` | Enum | ○ | `draft` / `published` / `archived` | |
| `related_anthologies` | Anthology[] | - | 関連企画（手動設定） | |

### ページテンプレート

- **一覧ページ**（`/anthologies`）：カード形式。表紙画像・タイトル・テーマ・タグ・収録作数を表示
- **詳細ページ**（`/anthologies/[slug]`）：概要・編集後記・収録作リスト（順序付き）・関連企画

---

## 2. 収録作（work）

### 説明

アンソロジー企画に属する個別作品。小説・詩・エッセイ・評論など形式は問わない。  
作品単体でもアクセスできる独立したページを持つ。

### フィールド定義

| フィールド名 | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `title` | String | ○ | 作品タイトル | 「縁側の虫」 |
| `slug` | String | ○ | URLスラッグ | `engawa-no-mushi` |
| `author_name` | String | ○ | 著者名（表示名） | 「山田 花子」 |
| `author_bio` | Text | - | 著者プロフィール（100字程度） | |
| `anthology` | Anthology | ○ | 所属するアンソロジー企画（参照） | |
| `format` | Enum | ○ | `novel`/`poem`/`essay`/`review`/`other` | |
| `body` | RichText | ○ | 本文（全文 or 抜粋）| Markdown/リッチテキスト |
| `is_excerpt` | Boolean | ○ | 抜粋フラグ（trueの場合は「続きは〜」を表示） | |
| `word_count` | Number | - | 文字数（自動計算推奨） | 3200 |
| `tags` | Tag[] | ○ | 関連タグ（2〜4個） | |
| `cover_image` | Image | - | 作品画像（任意） | |
| `published_at` | DateTime | ○ | 公開日時 | |
| `permission_granted` | Boolean | ○ | 著作権許諾確認フラグ（外部作品の場合） | |
| `permission_note` | Text | - | 許諾内容のメモ（内部管理用・非公開） | |
| `status` | Enum | ○ | `draft` / `published` / `archived` | |

### ページテンプレート

- **一覧ページ**（`/works`）：企画単位のグループ表示またはタグ絞り込み
- **詳細ページ**（`/works/[slug]`）：本文・著者情報・所属企画リンク・関連作品

---

## 3. 記事（article）

### 説明

編集部による解説・書評・インタビュー・エッセイ等の編集コンテンツ。  
作品を「解説する」「発見する」文脈で読者を引き込む役割を持つ。

### フィールド定義

| フィールド名 | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `title` | String | ○ | 記事タイトル | 「夜の文学が教えてくれること」 |
| `slug` | String | ○ | URLスラッグ | `yoru-no-bungaku` |
| `author_name` | String | ○ | 執筆者名（編集部名義可） | 「編集部」 |
| `article_type` | Enum | ○ | `review`/`interview`/`essay`/`feature`/`news` | |
| `body` | RichText | ○ | 本文 | |
| `cover_image` | Image | ○ | アイキャッチ画像 | |
| `excerpt` | Text | ○ | 記事概要（80〜120字、一覧表示用） | |
| `tags` | Tag[] | ○ | 関連タグ（3〜5個） | |
| `related_anthologies` | Anthology[] | - | 関連企画（手動設定） | |
| `related_works` | Work[] | - | 関連収録作（手動設定） | |
| `published_at` | DateTime | ○ | 公開日時 | |
| `status` | Enum | ○ | `draft` / `published` / `archived` | |

### ページテンプレート

- **一覧ページ**（`/articles`）：日付降順。カード形式（アイキャッチ・タイトル・概要・タグ）
- **詳細ページ**（`/articles/[slug]`）：本文・関連企画・関連収録作・タグ

## 4. スポット（spot）

> **注意：定義は未確定（未決事項 B-2 の回答待ち）。以下は暫定案A（ピックアップキュレーション）の定義。**

### 説明（暫定・案A）

編集部がテーマを設定して既存コンテンツをピックアップする「特集ショートコンテンツ」。  
トップページ上部に常時3〜5件を表示し、回遊のきっかけを作る。

### フィールド定義（暫定）

| フィールド名 | 型 | 必須 | 説明 |
|---|---|---|---|
| `title` | String | ○ | スポットタイトル |
| `slug` | String | ○ | URLスラッグ |
| `lead_copy` | Text | ○ | リード文（50〜100字） |
| `cover_image` | Image | ○ | 画像 |
| `featured_content` | Union（Anthology/Work/Article） | ○ | 紹介するコンテンツ（参照） |
| `tags` | Tag[] | - | タグ（任意） |
| `display_order` | Number | ○ | トップページでの表示順 |
| `published_at` | DateTime | ○ | 公開日時 |
| `status` | Enum | ○ | `draft` / `published` / `archived` |

### ページテンプレート（暫定）

- 一覧ページは持たない（トップページのみ表示）、または `/spots` に一覧を設置

## 5. タグ（tag）

### 説明

コンテンツを横断して分類するラベル。ジャンル・テーマ・形式・時代など多軸で設定する。  
タグページが検索流入の受け皿になるため、SEOを意識した命名が必要。

### フィールド定義

| フィールド名 | 型 | 必須 | 説明 |
|---|---|---|---|
| `name` | String | ○ | タグ名（日本語） |
| `slug` | String | ○ | URLスラッグ（英数字） |
| `description` | Text | - | タグの説明（タグページのintroとして表示） |
| `category` | Enum | - | `genre`/`theme`/`format`/`era`/`mood` |

### 初期タグ案（暫定・20タグ程度）

**ジャンル**：短編小説、詩、エッセイ、書評、現代文学、日本文学  
**テーマ**：郷愁、家族、孤独、旅、都市、自然、記憶、日常  
**形式**：アンソロジー、特集、インタビュー  
**ムード**：静謐、ユーモア、ダーク、温かい

## コンテンツタイプ間の関連図

```
タグ ────────────────────────────────────┐
 │                                       │
 └─ アンソロジー企画 (1)                 │
         │                               │
         ├─ 収録作 (多) ─── タグ ────────┤
         │                               │
         └─ 記事（関連付け） ─── タグ ───┘

スポット ─── アンソロジー企画 or 収録作 or 記事 を参照
```

---

## 制約事項

- 収録作の `anthology` は必ず1つの企画に紐付ける（複数企画への重複収録はフェーズ2以降で検討）
- 外部著者の収録作は `permission_granted: true` が確認できるまで `status: draft` を維持
- タグは編集部で一元管理し、勝手に増やさない（タグのインフレ防止）
