## サイトマップ（全ページ一覧）

### MVP（Must）ページ

```
/ (トップページ)
├── /anthologies (アンソロジー企画一覧)
│   └── /anthologies/[slug] (アンソロジー企画詳細)
├── /works (収録作一覧) ← 企画横断で全収録作を一覧
│   └── /works/[slug] (収録作詳細)
├── /articles (記事一覧)
│   └── /articles/[slug] (記事詳細)
├── /tags (タグ一覧)
│   └── /tags/[tag] (タグ別コンテンツ一覧)
└── /about (このサイトについて)
```

```

│   └── /spots/[slug] (スポット詳細)
└── /contribute (寄稿について)
```

## ページ別仕様

### トップページ（`/`）

**目的**：初訪問者に世界観を伝え、最低1ページ先に誘導する

**表示セクション（上から順）**：

1. ヒーローエリア
   - キャッチコピー（ブランドステートメント）
   - 注目アンソロジー企画1本（フィーチャーカード）
2. スポット（ピックアップ）
   - 3〜5件をカルーセルまたはグリッド表示
3. 新着アンソロジー企画
   - 最新3件をカード表示
4. 新着記事
   - 最新3件をリスト表示
5. タグ一覧（人気タグ10件程度）

**導線**：
- ヒーロー → 企画詳細
- スポット → 各コンテンツ詳細
- 新着カード → 企画詳細 or 記事詳細
- タグ → タグ別一覧

---

### アンソロジー企画一覧（`/anthologies`）

**目的**：企画を発見しやすくする。タグ絞り込みによる探索をサポート

**表示要素**：
- タグフィルター（複数選択可）
- 企画カード一覧（表紙画像・タイトル・テーマ・タグ・収録作数）
- ページネーション（1ページ12件程度）

**ソート**：公開日降順（デフォルト）

---

### アンソロジー企画詳細（`/anthologies/[slug]`）

**目的**：企画の世界観を伝え、収録作への誘導を最大化する

**表示要素**：
- 表紙画像（OGP兼用）
- タイトル・テーマ・タグ
- 企画概要
- 収録作リスト（順序付き・各作品へのリンク）
- 編集後記（任意）
- 関連企画（サイドバーまたは下部）

**重要な導線**：
- 収録作リスト → 収録作詳細（最重要）
- タグ → タグ別一覧
- 関連企画 → 他の企画詳細

---

### 収録作詳細（`/works/[slug]`）

**目的**：作品を読んでもらいつつ、企画・関連作品への回遊を促す

**表示要素**：
- 作品タイトル・著者名・著者プロフィール
- 所属アンソロジー企画バナー（上部に必ず表示）
- 本文（全文 or 抜粋）
- タグ
- 同企画の他収録作（「次の収録作」ナビゲーション）
- 関連記事（タグマッチ）

**重要な導線**：
- 所属企画バナー → 企画詳細（戻り導線として最重要）
- 次の収録作 → 次の収録作詳細（連続読書体験）
- タグ → タグ別一覧

---

### 記事詳細（`/articles/[slug]`）

**目的**：編集コンテンツで読者の関心を深め、企画・収録作へ送客する

**表示要素**：
- アイキャッチ画像・タイトル・執筆者
- 本文
- タグ
- 関連アンソロジー企画（手動設定）
- 関連収録作（手動設定）

**重要な導線**：
- 関連アンソロジー企画 → 企画詳細（記事→企画の主要導線）
- 関連収録作 → 収録作詳細
- タグ → タグ別一覧

---

### タグ別コンテンツ一覧（`/tags/[tag]`）

**目的**：同テーマのコンテンツを横断して発見できる検索代替ページ

**表示要素**：
- タグ名・説明
- このタグが付いた全コンテンツ（企画・記事・収録作を統合表示）
- コンテンツタイプ別フィルター

**SEO注意点**：
- タグページにはユニークな導入文を設定（重複コンテンツ対策）
- または `noindex` を検討（タグ数が増えた場合）

## 主要導線フロー図

### 導線1：検索流入（作品・テーマ検索）

```
Google検索
    ↓
収録作詳細 or タグ別一覧
    ↓
所属アンソロジー企画詳細（★回遊の核）
    ↓
同企画の他収録作 → 収録作詳細（連続読書）
    ↓
関連記事 or 関連企画
```

### 導線2：SNSシェア流入

```
SNS（X/Instagram等）
    ↓
記事詳細 or 収録作詳細
    ↓
関連アンソロジー企画（記事・収録作ページの下部）
    ↓
企画詳細 → 収録作リスト
```

### 導線3：トップページ起点（リピーター・ブックマーク）

```
トップページ
    ↓
新着企画 or スポット
    ↓
企画詳細 → 収録作詳細（→ 次の収録作）
    ↓
タグ → タグ別一覧 → 他の企画発見
```

### 導線4：タグ回遊（横断探索）

```
任意のページのタグリンク
    ↓
タグ別一覧（企画・記事・収録作が混在）
    ↓
気になるコンテンツ詳細
    ↓
さらにタグをたどる（複数タグ回遊）
```

## ナビゲーション設計

### グローバルナビゲーション（全ページ共通・ヘッダー）

```
ロゴ | アンソロジー企画 | 記事 | タグ | (このサイトについて)
```

### フッター

```
ロゴ | このサイトについて | 寄稿について | SNSリンク | 著作権表示
```

### パンくずリスト（必須ページ）

- 収録作詳細：`トップ > アンソロジー企画一覧 > [企画タイトル] > [収録作タイトル]`
- 記事詳細：`トップ > 記事一覧 > [記事タイトル]`
- タグ別：`トップ > タグ一覧 > [タグ名]`

## 回遊強化チェックポイント

| 確認項目 | 対応ページ | 優先度 |
|---|---|---|
| 収録作詳細に「所属企画バナー」が上部にあるか | 収録作詳細 | 必須 |
| 企画詳細に収録作リストが全件表示されているか | 企画詳細 | 必須 |
| 記事詳細に「関連企画」ウィジェットがあるか | 記事詳細 | Must |
| タグリンクが全ページに設置されているか | 全コンテンツ詳細 | Must |
| 「次の収録作」ナビゲーションがあるか | 収録作詳細 | Should |
| 関連コンテンツのタグマッチが機能しているか | 全詳細ページ | Should |
